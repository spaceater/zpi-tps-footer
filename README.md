# @semanaut/zpi-session-tps-footer

Session id and live throughput for [pi](https://github.com/earendil-works/pi) in the footer.

Replaces pi's built-in footer and adds exactly two elements: the session id (right-aligned on line 1) and a live `<t/s>` measurement after the model name on line 2.

## Install

```bash
pi install npm:@semanaut/zpi-session-tps-footer
```
